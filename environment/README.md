# Окружение для запуска без интернета

`python/` — готовый к работе Python для Windows x64, ничего устанавливать не нужно.
Программа запускается так: `python\pythonw.exe ..\main.pyw` (это и делает `SZ.bat`).

| Компонент | Версия | Откуда |
|---|---|---|
| Python | 3.8.10, 64-разрядный | официальная сборка python.org, пакет NuGet `python` |
| PyQt5 | 5.15.11 | PyPI, колесо `cp38-abi3-win_amd64` |
| Qt | 5.15.2 | PyPI, колесо `PyQt5_Qt5` (библиотеки Qt и Visual C++) |
| PyQt5-sip | 12.15.0 | PyPI |

Python 3.8 выбран потому, что работает и на Windows 7/8.1, и на Windows 10/11.
SQLite (модуль `sqlite3`) входит в Python, документы Word программа формирует сама,
поэтому других библиотек не нужно.

## Что убрано

Чтобы окружение было меньше, удалено то, что программе не нужно:

- из Python — заголовки и библиотеки для сборки расширений (`include`, `libs`) и примеры (`Tools`);
- из PyQt5 — все модули, кроме QtCore, QtGui и QtWidgets (QML, мультимедиа, сеть, WebEngine и т. д.),
  программный OpenGL (`opengl32sw.dll`), лишние плагины и переводы (остался `qtbase_ru.qm`).

`pip` оставлен: дополнительные колёса можно поставить без интернета командой
`python\python.exe -m pip install --no-index --find-links <папка с .whl> <пакет>`.

Файл `python\python38._pth` ограничивает пути поиска модулей этой папкой, поэтому
переменные `PYTHONPATH`/`PYTHONHOME` и другие установленные Python не мешают.

## Пересборка

На компьютере с интернетом: `python build_environment.py`. Скрипт скачивает те же версии,
сверяет SHA-256, ставит PyQt5, удаляет лишнее и (если установлен `pefile`) проверяет, что
всем DLL хватает библиотек.
