# Служебные записки

Программа для создания служебных записок (СЗ) в закрытой сети без интернета и без
сервера-приложения. Это отдельное окно Windows (Python + PyQt5), а не страница в браузере:
программа сама создаёт базу данных, папки и документы Word в общей папке.

Всё нужное для работы лежит в папке `environment`: Python 3.8 и библиотека PyQt5.
**Ничего скачивать и устанавливать не нужно**, интернет не требуется.

## Установка

1. Скопируйте папку программы целиком (`SZ.vbs`, `SZ.bat`, `main.pyw`, `sz/`, `environment/`)
   в общую сетевую папку, например `\\server\Общие\СЗ`.
2. Дайте пользователям право **на чтение и запись** в эту папку.
3. Пользователи запускают **`SZ.vbs`** двойным щелчком (удобно сделать на него ярлык на рабочем
   столе).

### Запуск из сетевой папки

- **`SZ.vbs`** — основной способ: работает из папки вида `\\server\...` и не показывает окно
  консоли.
- **`SZ.bat`** тоже запускает программу, но если открыть его из сетевой папки, командная строка
  Windows сначала напишет «Cmd.exe не поддерживает пути UNC. По умолчанию выбрана системная папка
  Windows». Это только предупреждение: программа запускается по полному пути и работает
  нормально. Убрать его изнутри `.bat` нельзя, поэтому из сетевой папки лучше запускать `SZ.vbs`.
- Если запуск `.vbs` запрещён политикой безопасности (или VBScript отключён в Windows 11),
  сделайте пользователям ярлык. В поле «Объект» укажите
  `\\server\Общие\СЗ\environment\python\pythonw.exe "\\server\Общие\СЗ\main.pyw"`,
  в поле «Рабочая папка» — `\\server\Общие\СЗ`. Такой ярлык можно разослать
  администратором (например, групповой политикой).
- Можно и подключить общую папку буквой диска (например, `Z:`): тогда `SZ.bat` запускается без
  предупреждения.

База `data/memos.db` и документы Word создаются рядом с программой при первом запуске.

### Программа на каждом компьютере, данные в общей папке

Если запускать программу из сетевой папки медленно, её можно скопировать на каждый компьютер
(например, в `C:\СЗ`), а общую папку указать одним из способов:

- в программе: **Справочники → Настройки → Выбрать другую папку…** (запоминается для
  пользователя Windows) или кнопка «Сменить папку» внизу бокового меню;
- для всех сразу: скопировать `sz.ini.example` в `sz.ini` рядом с программой и вписать путь
  в строку `folder = \\server\Общие\СЗ`.

Если папка недоступна (нет сети, нет прав), программа покажет это и предложит повторить или
выбрать другую папку.

### Требования

- Windows 10 или 11, 64-разрядная. Работает и на Windows 7 SP1 / 8.1 x64, если установлены
  обновления KB2533623 и KB2999226 (универсальная библиотека C), они обычно уже стоят.
- Microsoft Word или другой редактор `.docx`, чтобы открывать готовые записки.

## Что где лежит

```
SZ.vbs                  запуск программы (в том числе из сетевой папки)
SZ.bat                  запуск программы через командную строку
SZ-console.bat          запуск с окном консоли: видны сообщения об ошибках
main.pyw                точка входа
sz/                     код программы
  docx.py                 формирование документа Word (без внешних библиотек)
  store.py                база SQLite и блокировка записи
  actions.py              создание СЗ, справочники, настройки, статистика
  ui/                     окна и страницы PyQt5 (editor.py - поле «Текст» с оформлением)
environment/            всё для запуска без интернета
  python/                 Python 3.8.10 для Windows x64 и PyQt5 5.15
  build_environment.py    пересборка окружения (нужен интернет)
tests/                  автоматические проверки
tools/recover_db.py     проверка и восстановление повреждённой базы
sz.ini.example          пример настройки общей папки

data/memos.db           база данных SQLite (создаётся при первом запуске)
data/memos.lock         временная блокировка во время записи (удаляется сама)
Служебные записки/      документы Word: <год>/<номер СЗ>/<номер СЗ>.docx,
                        например 2026/НТЦ-0001-26/НТЦ-0001-26.docx
```

## Переход с браузерной версии (SZ.html)

Формат базы тот же. Положите программу в ту же общую папку, где лежал `SZ.html`, и запустите
`SZ.vbs`: она откроет существующую `data/memos.db` и продолжит нумерацию, старые записки и
документы Word останутся на месте. Документы формируются в точности как раньше.

Переведите на программу всех пользователей сразу: браузерная версия перезаписывает файл базы
целиком, и пока программа держит базу открытой, у браузера сохранение не пройдёт.

## Настройки (Справочники → Настройки)

- **Наименование организации** печатается в шапке каждой СЗ, каждая строка отдельно.
- **Город** печатается под заголовком.
- **Префикс номера**: по умолчанию `НТЦ`.
- **Папка для документов Word**: путь внутри общей папки.
- **Общая папка на этом компьютере**: где лежат база и документы.

## Номер СЗ

Формат `НТЦ-XXXX-YY`: `XXXX` — порядковый номер с ведущими нулями, `YY` — две последние
цифры года из даты записки. С каждым годом нумерация начинается с `0001`. Номер присваивается
при сохранении и хранится в записке, поэтому смена префикса не меняет уже выпущенные номера.

## Страницы

- **Новая СЗ**: тематика работ, один или несколько адресатов, дата, текст, приложение,
  исполнитель; подписант подставляется сам. Справа сразу видно, как записка будет выглядеть
  в Word. Текст можно оформить: полужирный, курсив, размер, выравнивание (см. «Оформление
  текста»). После сохранения в папке создаётся документ Word. Набранный текст не пропадает при
  переходе на другие страницы, пока записка не сохранена.
- **Реестр**: список с поиском (по мере ввода) и фильтрами по тематике и году. Двойной щелчок
  открывает записку.
- **Просмотр СЗ**: все данные записки и лист, кнопки «Открыть Word», «Показать в папке»,
  «Сформировать Word заново», «Удалить из реестра» (файл Word при этом остаётся).
- **Статистика**: число СЗ за год, по месяцам (графиком или таблицей), по тематикам, адресатам
  и исполнителям.
- **Справочники**: сотрудники (ФИО, должность, телефон, подписант), адресаты (отдел,
  должность и ФИО руководителя), тематики работ, настройки. Запись изменяется двойным
  щелчком или кнопкой «Изменить».

Данные из справочников копируются в записку в момент создания, поэтому правка или удаление
сотрудника или адресата не меняет уже созданные СЗ.

## Шаблон СЗ (Arial 14)

Шапка с наименованием организации (полужирным, переносы как в настройках) →
«СЛУЖЕБНАЯ ЗАПИСКА» → город → дата слева и номер справа → адресаты справа
(должность и под ней «Фамилия И.О.», в дательном падеже) → тематика работ → обращение
(«Уважаемый Имя Отчество!», для нескольких адресатов «Уважаемые Коллеги!») → текст →
приложение → должность подписанта слева и его Фамилия И.О. справа → исполнитель и телефон
шрифтом 10.

### Оформление текста

Над полем «Текст» есть панель оформления, результат сразу виден на листе справа и в Word:

| Кнопка | Что делает | Клавиши |
|---|---|---|
| **Ж** / *К* / <u>Ч</u> | полужирный, курсив, подчёркнутый | Ctrl+B / Ctrl+I / Ctrl+U |
| 10–16 | размер шрифта выделенного текста (обычный — 14) | |
| выравнивание | по левому краю, по центру, по правому краю, по ширине | Ctrl+L / Ctrl+E / Ctrl+R / Ctrl+J |
| отступ | отступ первой строки абзаца 1,25 см вкл/выкл | |
| ↵ | перенос строки внутри абзаца | Shift+Enter |
| ✕ | убрать оформление: шрифт 14, по ширине, с отступом | |

Enter начинает новый абзац. По умолчанию абзац выровнен по ширине и с отступом первой
строки, как в шаблоне. При вставке текста из Word, браузера или почты сохраняются только
полужирный, курсив и подчёркивание, а чужие шрифты, цвета и размеры отбрасываются, чтобы
записки оставались единообразными.

Оформление хранится в колонке `memos.body_rich` (JSON). Обычный текст записки по-прежнему
лежит в `memos.body`, по нему работает поиск. У записок без оформления `body_rich` пустая.

В справочниках ФИО хранится полностью, в документе печатается кратко. Для адресата
должность и «Фамилию И.О.» в дательном падеже («Начальнику отдела», «Петрову П.П.») вносят
в справочник вручную, полное ФИО нужно для обращения по имени и отчеству.

Подписант один на всех: его отмечают галочкой в справочнике «Сотрудники» (у остальных
галочка блокируется, пока её не снимут), и он подставляется во все новые записки
вместе со своей должностью.

## Одновременная работа нескольких пользователей

Программа работает с файлом базы напрямую. Перед каждой записью она создаёт файл
`data/memos.lock`, причём создание атомарное: на сетевой папке его может создать только один
компьютер, остальные ждут (обычно доли секунды). Поэтому изменения разных людей не затирают
друг друга, а номера СЗ не повторяются. Изменения коллег появляются на экране сами в течение
нескольких секунд и при возврате в окно программы.

Если программа аварийно закрылась во время записи, блокировка считается брошенной через
минуту и снимается автоматически. Схема рассчитана на отдел (единицы и десятки
пользователей).

## Резервное копирование

Достаточно копировать папку `data/` и папку с документами.
Базу `data/memos.db` можно открыть любой программой для SQLite, например DB Browser for SQLite.

## Если не работает

- **«Cmd.exe не поддерживает пути UNC»** при запуске `SZ.bat` или `SZ-console.bat` из сетевой
  папки: это предупреждение, программа всё равно запускается. Чтобы его не было, запускайте
  `SZ.vbs` (см. «Запуск из сетевой папки»).
- **Окно не появляется**: запустите `SZ-console.bat`, в консоли будет текст ошибки.
- **«database disk image is malformed» (база повреждена)**: закройте программу у всех и запустите
  проверку (в PowerShell; путь замените своим):
  ```
  & "\\server\Общие\СЗ\environment\python\python.exe" "\\server\Общие\СЗ\tools\recover_db.py" "\\server\Общие\СЗ\data\memos.db"
  ```
  Скрипт не меняет исходный файл: он работает с копией в папке `data\восстановление-<дата>`.
  Если база исправна, он так и скажет. Если повреждена, перенесёт всё, что читается, в
  `memos-восстановлена.db` и напишет, сколько строк не удалось прочитать. Её нужно положить в
  `data\` под именем `memos.db` вместо повреждённой (повреждённую не удаляйте, а переименуйте).
  Служебные файлы `memos.db-journal` и `memos.db-wal` рядом с базой не удаляйте: в них может
  быть незаконченная запись.
- **Не открывайте `memos.db` в текстовом редакторе** (VS Code, Блокнот): сохранение такого файла
  портит базу.
  Ошибки при обычном запуске пишутся в файл `sz-errors.log` во временной папке пользователя
  (`%TEMP%`).
- **«Не удалось открыть базу» / «Нет прав на запись»**: проверьте, что общая папка доступна и
  у пользователя есть право записи.
- **«База занята другим пользователем»** дольше минуты: в сообщении указано, кто держит
  блокировку. Если этот человек ничего не сохраняет, удалите `data/memos.lock`.
- **«Не удалось записать … файл открыт в Word»**: закройте документ в Word и повторите.

## Для разработчика

Проверки (нужен Python 3.8+ и PyQt5; на Windows можно взять из окружения):

```
environment\python\python.exe -m unittest discover -s tests
```

Пересборка окружения на компьютере с интернетом (скачивает Python с NuGet и PyQt5 с PyPI,
проверяет контрольные суммы, удаляет ненужные модули Qt):

```
python environment/build_environment.py
```
