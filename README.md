# Служебные записки

Создание служебных записок (СЗ) в закрытой сети без интернета и без сервера-приложения.
Всё находится в одной общей папке: пользователи открывают **SZ.html** в браузере,
база данных и документы Word лежат рядом.

## Установка

1. Скопируйте папку целиком (`SZ.html` и `app/`) в общую сетевую папку, например
   `\\server\Общие\СЗ`.
2. Дайте пользователям право **на чтение и запись** в эту папку.
3. Отправьте всем ссылку на папку. Больше ничего устанавливать не нужно.

Нужен Google Chrome, Microsoft Edge или Яндекс Браузер (Chromium 86+).
Firefox и Internet Explorer не подходят: в них страница не может записывать файлы в папку.

## Первый запуск у пользователя

1. Открыть `SZ.html` двойным щелчком и нажать **«Войти»**.
2. Только при первом входе на компьютере браузер откроет окно выбора папки: выбрать папку,
   где лежит `SZ.html` (её путь написан на странице), затем «Разрешить».

Указать папку по пути браузер не позволяет, поэтому первый раз её выбирают в окне. Если
выбрана не та папка, приложение сообщит об этом и попросит выбрать снова. Дальше «Войти»
только спрашивает разрешение. В Chrome и Edge 122+ в этом окне есть вариант «Разрешать при
каждом посещении», и после него страница открывается сразу, без кнопки.

## Что где лежит

```
SZ.html                 страница приложения
app/                    скрипты, стили, шрифт IBM Plex Sans и библиотека SQLite (sql.js);
                        ничего не грузится из интернета
tests/                  проверки для разработчика: node tests/docx-test.js,
                        node tests/browser-test.js (нужен Playwright с Chromium)
data/memos.db           база данных SQLite (создаётся при первом запуске)
data/memos.lock         временная блокировка во время записи (удаляется сама)
Служебные записки/      документы Word: <год>/<номер СЗ>/<номер СЗ>.docx,
                        например 2026/НТЦ-0001-26/НТЦ-0001-26.docx
```

## Настройки (Справочники → Настройки)

- **Наименование организации** печатается в шапке каждой СЗ, каждая строка отдельно.
- **Префикс номера**: по умолчанию `НТЦ`.
- **Папка для документов Word**: путь внутри общей папки.

## Номер СЗ

Формат `НТЦ-XXXX-YY`: `XXXX` — порядковый номер с ведущими нулями, `YY` — две последние
цифры года из даты записки. С каждым годом нумерация начинается с `0001`. Номер присваивается
при сохранении и хранится в записке, поэтому смена префикса не меняет уже выпущенные номера.

## Страницы

- **Новая СЗ**: тематика работ, один или несколько адресатов, дата, текст, приложение,
  исполнитель; подписант подставляется сам. Справа сразу видно, как записка будет выглядеть в Word.
  Текст можно оформить (см. «Оформление текста»). После сохранения в папке создаётся документ Word.

## Шаблон СЗ (Arial 14)

Шапка с наименованием организации (полужирным, переносы как в настройках) →
«СЛУЖЕБНАЯ ЗАПИСКА» → город → дата слева и номер справа → адресаты справа
(должность и под ней «Фамилия И.О.», в дательном падеже) → тематика работ → обращение («Уважаемый Имя Отчество!», для нескольких
адресатов «Уважаемые Коллеги!») → текст → приложение → должность подписанта слева и его
Фамилия И.О. справа → исполнитель и телефон шрифтом 10.

### Оформление текста

Над полем «Текст» есть панель оформления, результат сразу виден на листе справа и в Word:

| Кнопка | Что делает | Клавиши |
|---|---|---|
| **Ж** / *К* / <u>Ч</u> | полужирный, курсив, подчёркнутый | Ctrl+B / Ctrl+I / Ctrl+U |
| 10–16 | размер шрифта выделенного текста (обычный — 14) | |
| выравнивание | по левому краю, по центру, по правому краю, по ширине | |
| отступ | отступ первой строки абзаца 1,25 см вкл/выкл | |
| ↵ | перенос строки внутри абзаца | Shift+Enter |
| ✕ | убрать оформление: шрифт 14, по ширине, с отступом | |

Enter начинает новый абзац, Ctrl+Z / Ctrl+Y отменяют и возвращают действия, включая
оформление. Если нажать кнопку без выделения, оформление применится к тексту, который будет
набран дальше. У выравнивания нет сочетаний клавиш: привычные по Word Ctrl+L, Ctrl+E, Ctrl+R
и Ctrl+J в браузере заняты (Ctrl+R обновил бы страницу и стёр набранный текст).

При вставке из Word, другой страницы или почты сохраняются только полужирный, курсив и
подчёркивание, а чужие шрифты, цвета и размеры отбрасываются, чтобы записки оставались
единообразными.

Оформление хранится в колонке `memos.body_rich` (JSON), обычный текст записки по-прежнему
лежит в `memos.body`, по нему работает поиск. У записок без оформления `body_rich` пустая.
Формат тот же, что у настольной версии (ветка `pyqt-desktop`).

В справочниках ФИО хранится полностью, в документе печатается кратко. Для адресата
должность и «Фамилию И.О.» в дательном падеже («Начальнику отдела», «Петрову П.П.») вносят
в справочник вручную, полное ФИО нужно для обращения по имени и отчеству.

Подписант один на всех: его отмечают галочкой в справочнике «Сотрудники» (у остальных
галочка блокируется, пока её не снимут), и он подставляется во все новые записки
вместе со своей должностью.
- **Статистика**: число СЗ за год, распределение по месяцам, по тематикам, адресатам и
  исполнителям.
- **Справочники**: сотрудники (ФИО, телефон), адресаты (отдел, должность и ФИО
  руководителя), тематики работ, настройки.
- **Реестр СЗ**: список с поиском и фильтрами, просмотр, скачивание Word, повторное
  формирование файла, удаление из реестра (файл Word при этом остаётся).

Данные из справочников копируются в записку в момент создания, поэтому правка или удаление
сотрудника или адресата не меняет уже созданные СЗ.

## Одновременная работа

Пока один пользователь сохраняет изменения, остальные ждут, обычно доли секунды.
Перед каждой записью база перечитывается с диска, поэтому изменения разных людей не
затирают друг друга, а номера СЗ не повторяются. Изменения коллег подтягиваются при
переходе между страницами и при возврате в окно браузера.

Блокировка через файл на сетевой папке не абсолютна, поэтому после каждого сохранения
браузер через 0,7 с перечитывает базу и проверяет, что его изменение на месте (каждое
сохранение оставляет код в таблице `write_log`). Если его затёр другой пользователь,
действие автоматически повторяется на свежих данных: новая СЗ получает следующий номер,
а документ Word создаётся только после подтверждения номера. Поэтому каждое сохранение
длится примерно на секунду дольше.

Схема рассчитана на отдел (единицы и десятки пользователей), а не на сотни одновременных
сохранений.

## Резервное копирование

Достаточно копировать папку `data/` и папку с документами.
Базу `data/memos.db` можно открыть любой программой для SQLite, например DB Browser for SQLite.

## Если не работает

- **«Браузер не поддерживается»**: откройте файл в Chrome, Edge или Яндекс Браузере.
- **Ошибка доступа при сохранении**: проверьте права на запись в общую папку.
- **Кнопка выбора папки ничего не делает или выдаёт ошибку безопасности**: доступ к файлам
  мог запретить администратор групповой политикой браузера (`DefaultFileSystemWriteGuardSetting`,
  `FileSystemWriteBlockedForUrls`). Нужно разрешить его для адресов `file://`.
- **«База занята другим пользователем»** дольше минуты: удалите `data/memos.lock`, если
  никто не сохраняет данные в этот момент.
