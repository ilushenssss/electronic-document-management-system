# Служебные записки

## Перенос номера СЭД из старого журнала Excel

Новый скрипт `tools/import_sed_numbers.py` обновляет только существующие СЗ.
Он сопоставляет колонку «Номер СЗ» с полным номером в БД, включая префикс и год,
и переносит значение «Номер СЗ 1С» в `sed_number`/`in_paper`:

- `1/441062/1100/СЗ` и варианты с разделителями `\`, `_`, `|`, дефисами,
  точками, двоеточиями, запятыми, `?`, `*`, пробелами преобразуются в номер со слешами.
  Регистр окончания не важен, ведущие нули сохраняются.
- «В бумаге» и «в отд.40» (без учёта регистра, точек и пробелов) дают отметку «В бумаге».
- Пустые и остальные нераспознанные значения дают пустой номер и снимают отметку.
  **Это очищает и ранее заполненные значения в совпавших СЗ.**

Принимается целое значение в формате номера; номер из произвольного текста
не извлекается. Ненайденные СЗ, неоднозначные номера в БД и противоречивые дубликаты
Excel пропускаются с указанием причины. Формулы без сохранённого результата
пропускаются: сначала пересохраните журнал в Excel.
Word, PDF, пути сканов и все остальные сведения СЗ скрипт не меняет.

Добавьте скрипт в `tools/` актуальной версии приложения. Закройте приложение
у всех пользователей. В PowerShell из общей папки сначала выполните проверку:

```powershell
& ".\environment\python\python.exe" ".\tools\import_sed_numbers.py" "C:\журнал.xlsx" "." --dry-run
```

Откройте указанный CSV-отчёт: в нём видны исходное значение, прежнее состояние,
результат преобразования и пропуски. Для записи повторите команду без `--dry-run`
и подтвердите изменения. Скрипт использует `openpyxl` из существующего окружения,
первый лист и заголовки в первых 30 строках; другой лист выбирается через `--sheet`.
Вместо общей папки можно передать полный путь к `data/memos.db`.

Перед записью под общей блокировкой создаётся копия базы через SQLite `backup()`,
проверяется `integrity_check`; изменения применяются одной транзакцией.
Если данные изменились после предварительного отчёта, импорт полностью отменяется.
Новые таблицы/колонки и СЗ не создаются. Повторный запуск с тем же журналом
не меняет уже совпадающие значения. `--yes` разрешает запись без вопроса,
включая очистку номеров; `--report` задаёт путь к CSV-отчёту.

## Отметка «В бумаге» и отсутствие номера СЭД

После выбора/перетаскивания PDF в окне номера можно поставить «В бумаге».
Номер СЭД тогда вводить не требуется: скан сохраняется под внутренним номером,
например `НТЦ-0001-26.pdf`, а в колонке «Номер СЭД» отображается «В бумаге».
Отметка хранится в отдельном поле `memos.in_paper`; само `sed_number` остаётся пустым.

В карточке отметку также можно установить/снять отдельно. Для перехода к СЭД
снимите галочку, введите номер и сохраните. Уже привязанный PDF переименуется
с учётом выбранного режима; подтверждение замены и резервные версии действуют
как при обычной загрузке.

В реестре включите «Без номера СЭД», чтобы увидеть СЗ без номера и без отметки
«В бумаге». Фильтр работает по всей базе вместе с остальными условиями,
возвращает первую страницу и очищается кнопкой «Сбросить».

Для установки замените вместе `sz/store.py`, `sz/scans.py`, `sz/actions.py`
и `sz/ui/pages.py`. Перед обновлением закройте приложение у всех пользователей
и сохраните копию базы. Поле `in_paper` добавляется автоматически, у существующих
СЗ оно выключено; прежние номера СЭД и сканы сохраняются.

## Скан PDF и номер СЭД

В карточке СЗ нажмите «Выбрать PDF» или перетащите один локальный PDF в карточку
(включая область предпросмотра). Затем введите номер из другой системы, например `1/441062/1100/СЗ`.
Допускаются три группы цифр и окончание `/СЗ`; ведущие нули сохраняются.
Окно показывает будущее имя файла: `1_441062_1100_СЗ.pdf`.
Перетаскивание принимает существующий файл и одиночное PDF-вложение Outlook
через Windows FileGroupDescriptor/FileContents. Вложение временно сохраняется
на диск, после ввода номера копируется в папку СЗ; временный файл удаляется
также при отмене. Перетаскивание письма целиком или нескольких вложений не поддерживается.
Если версия Outlook не передаёт виртуальный PDF (например, вместо него передаётся
веб-ссылка), сохраните PDF на диск и выберите кнопкой или перетащите из Проводника.
В Windows приложение и Проводник должны работать с одинаковым уровнем прав:
обычно оба без запуска от имени администратора.
При отмене диалога загрузка и изменение базы не выполняются.

Скан копируется в папку текущей СЗ рядом с Word, исходный файл остаётся на месте.
В реестре появилась колонка «Номер СЭД» после внутреннего номера СЗ, по нему
работает общий поиск. Для открытия PDF используйте «Открыть скан PDF» в карточке.

Отдельное поле «Номер СЭД» и кнопка сохранения позволяют записать/исправить номер
без загрузки файла. Если PDF уже привязан, изменение номера переименовывает его.
Если скан скопирован в папку вручную, назовите его по тому же правилу
(`1_441062_1100_СЗ.pdf`) и сохраните номер: приложение найдёт и привяжет PDF.
Номер можно сохранить и до появления скана; после ручного копирования откройте
карточку заново. Для PDF с произвольным именем используйте выбор файла.

При совпадении имени требуется подтверждение замены, предыдущий PDF сохраняется
в подпапке «Предыдущие версии». Если файл открыт/нет прав, номер в базе не меняется.
Проверяются расширение и заголовок PDF. Одновременная правка номера другим
пользователем блокирует сохранение до повторного открытия карточки.

Для обновления замените `sz/actions.py`, `sz/store.py`, `sz/ui/pages.py`,
`sz/ui/window.py` и добавьте новый файл `sz/scans.py`. Закройте приложение у всех пользователей и сделайте
резервную копию `data/memos.db` перед первым запуском. Приложение автоматически
добавит в `memos` поля `sed_number` и `scan_path`, существующие СЗ сохранятся.
Скан и номер СЭД не изменяют внутренний номер СЗ, имя Word и содержимое Word.

## Редактирование существующей СЗ

Откройте СЗ из реестра и нажмите «Редактировать» вместо прежней кнопки
повторного формирования Word. Форма открывается из сохранённых данных СЗ:
значения «из СЗ» сохраняют прежние сведения даже после изменения справочников.
Можно выбрать актуальную тематику, исполнителя и адресатов из справочников;
подписант, шапка и город сохраняются из исходной СЗ.

«Сохранить изменения и обновить Word» обновляет ту же запись с прежним номером
и документ по прежнему пути. Дату можно менять в пределах года номера.
Перед заменой существующий Word копируется в подпапку «Предыдущие версии»
рядом с документом. Замена выполняется через временный файл без предварительного
обнуления оригинала.

Если Word открыт или нет прав на запись, изменения сохраняются в реестре,
форма остаётся открытой с предупреждением. Закройте документ/устраните ошибку
и нажмите повторное сохранение. До успешной замены файл Word содержит старую
версию данных. При уходе из изменённой формы или закрытии приложения появится
предупреждение. Отмена редактирования не отменяет уже сохранённые в базе правки.

Если коллега изменил или удалил СЗ после открытия формы, сохранение блокируется.
Кнопка «Перечитать СЗ» загружает актуальную версию, сохраняя введённый текст и
приложение для просмотра кнопкой «Показать мой предыдущий текст».
Этот текст хранится в памяти текущего сеанса, до закрытия приложения или
открытия другой СЗ на редактирование. Черновик новой СЗ остаётся в отдельной форме.

Для установки замените вместе `sz/actions.py`, `sz/store.py`, `sz/ui/pages.py`
и `sz/ui/window.py`. Миграция схемы базы не требуется. На время обновления
закройте приложение у всех пользователей; для защиты от конфликтов все рабочие
места должны использовать обновлённый код.

Реестр отображается страницами по 25 СЗ, от новых номеров к старым.
Кнопки «Назад» и «Далее» переключают страницы; счётчики показывают номер
страницы и диапазон записей. Поиск и фильтры применяются ко всему реестру,
при смене условий открывается первая страница. После удаления последней
записи на странице выбирается ближайшая существующая страница.
Карточка и подсказка полного текста работают как прежде.
Запрос к SQLite выбирает только одну страницу и адресатов этих записок;
поиск без учёта регистра кириллицы выполняется до ограничения выборки.
Обновление требует совместной замены `sz/actions.py`, `sz/store.py` и
`sz/ui/pages.py`; миграция базы не нужна.

В реестре колонка «Текст СЗ» показывает первые 200 символов тела записки
и многоточие, если текст длиннее. Переносы и повторные пробелы в колонке
заменяются одним пробелом. При наведении на любую ячейку строки полный текст
показывается в подсказке с исходными переносами. Двойной щелчок и кнопка
«Открыть» по-прежнему открывают карточку СЗ. Лимит задаётся константой
`RegistryPage.BODY_PREVIEW_LIMIT` в `sz/ui/pages.py`; база не меняется.

В реестре показаны границы ячеек; «Текст СЗ» расположен сразу после тематики.
Тематика имеет фиксированную ширину примерно 10 символов, полное название
видно при наведении. «Текст СЗ» занимает оставшуюся ширину таблицы.
Фильтры по исполнителю и адресату (отделу) работают совместно с поиском,
тематикой и годом. Списки берутся из сохранённых СЗ, поэтому доступны также
исторические значения после изменения справочников. Фильтр адресата проверяет
всех получателей записки. «Сбросить» очищает все условия реестра.

В форме новой СЗ над исполнителем есть поиск по ФИО и телефону, с кнопкой
очистки. Поиск сужает список, не снимая сделанный выбор исполнителя.
Кнопка «Очистить» сбрасывает тематику, адресатов, исполнителя, текст, приложение
и обе строки поиска. Дата возвращается на сегодня; назначенный в справочнике
подписант сохраняется. Записи в реестре и справочники эта кнопка не меняет.

## Обновление оформления Word

- В справочнике «Адресаты» поле должности многострочное: Enter задаёт перенос строки,
  как у должности сотрудника. Откройте существующую запись кнопкой «Изменить»,
  расставьте переносы и сохраните. Пересоздавать справочники или базу не требуется.
- Поля Word: верхнее 1,5 см, левое 2,5 см, правое 1 см.
  Нижнее поле основного текста рассчитывается по высоте исполнителя и телефона:
  отступ колонтитула от края 1 см, высота строк и зазор 0,3 см.
  При двух строках шрифтом 11 пт нижнее поле составляет примерно 2,36 см.
- Междустрочный интервал тела СЗ — 1,5, включая текст с оформлением.
- Исполнитель и телефон размещаются в нижнем колонтитуле последней страницы,
  шрифт 11. Размер задаётся одной константой `EXECUTOR_FONT_SIZE` в `sz/docx.py`
  и применяется также после обновления полей Word. Последняя страница определяется полями Word PAGE/NUMPAGES;
  документ запрашивает обновление полей при открытии. Если Word отключил автоматическое
  обновление, обновите поля в нижнем колонтитуле (выделить его содержимое и нажать F9).
  Просмотрщики без поддержки вычисления полей могут показывать исполнителя на всех страницах.
  Экранный лист PyQt — непрерывный предварительный просмотр, без пагинации Word.

Изменения справочников применяются к новым СЗ: существующие записки сохраняют снимки
данных адресатов. Чтобы применить новые поля, интервалы и колонтитул к старому документу,
откройте «Редактировать» и сохраните СЗ без изменения значений «из СЗ».

Программа для создания служебных записок (СЗ) в закрытой сети без интернета и без
сервера-приложения. Это отдельное окно Windows (Python + PyQt5), а не страница в браузере:
программа сама создаёт базу данных, папки и документы Word в общей папке.

Всё нужное для работы лежит в папке `environment`: Python 3.8 и библиотека PyQt5.
**Ничего скачивать и устанавливать не нужно**, интернет не требуется.

## Установка

1. Скопируйте папку программы целиком (`SZ.vbs`, `SZ.bat`, `main.pyw`, `sz/`, `environment/`)
   в общую сетевую папку, например `\\server\Общие\СЗ`.
2. Дайте пользователям право **на чтение и запись** в эту папку.
3. Пользователи запускают **`SZ.vbs`** двойным щелчком (удобно сделать на него ярлык на рабочем
   столе).

### Запуск из сетевой папки

- **`SZ.vbs`** — основной способ: работает из папки вида `\\server\...` и не показывает окно
  консоли.
- **`SZ.bat`** тоже запускает программу, но если открыть его из сетевой папки, командная строка
  Windows сначала напишет «Cmd.exe не поддерживает пути UNC. По умолчанию выбрана системная папка
  Windows». Это только предупреждение: программа запускается по полному пути и работает
  нормально. Убрать его изнутри `.bat` нельзя, поэтому из сетевой папки лучше запускать `SZ.vbs`.
- Если запуск `.vbs` запрещён политикой безопасности (или VBScript отключён в Windows 11),
  сделайте пользователям ярлык. В поле «Объект» укажите
  `\\server\Общие\СЗ\environment\python\pythonw.exe "\\server\Общие\СЗ\main.pyw"`,
  в поле «Рабочая папка» — `\\server\Общие\СЗ`. Такой ярлык можно разослать
  администратором (например, групповой политикой).
- Можно и подключить общую папку буквой диска (например, `Z:`): тогда `SZ.bat` запускается без
  предупреждения.

База `data/memos.db` и документы Word создаются рядом с программой при первом запуске.

### Программа на каждом компьютере, данные в общей папке

Если запускать программу из сетевой папки медленно, её можно скопировать на каждый компьютер
(например, в `C:\СЗ`), а общую папку указать одним из способов:

- в программе: **Справочники → Настройки → Выбрать другую папку…** (запоминается для
  пользователя Windows) или кнопка «Сменить папку» внизу бокового меню;
- для всех сразу: скопировать `sz.ini.example` в `sz.ini` рядом с программой и вписать путь
  в строку `folder = \\server\Общие\СЗ`.

Если папка недоступна (нет сети, нет прав), программа покажет это и предложит повторить или
выбрать другую папку.

### Требования

- Windows 10 или 11, 64-разрядная. Работает и на Windows 7 SP1 / 8.1 x64, если установлены
  обновления KB2533623 и KB2999226 (универсальная библиотека C), они обычно уже стоят.
- Microsoft Word или другой редактор `.docx`, чтобы открывать готовые записки.

## Что где лежит

```
SZ.vbs                  запуск программы (в том числе из сетевой папки)
SZ.bat                  запуск программы через командную строку
SZ-console.bat          запуск с окном консоли: видны сообщения об ошибках
main.pyw                точка входа
sz/                     код программы
  docx.py                 формирование документа Word (без внешних библиотек)
  store.py                база SQLite и блокировка записи
  actions.py              создание СЗ, справочники, настройки, статистика
  ui/                     окна и страницы PyQt5 (editor.py - поле «Текст» с оформлением)
environment/            всё для запуска без интернета
  python/                 Python 3.8.10 для Windows x64 и PyQt5 5.15
  build_environment.py    пересборка окружения (нужен интернет)
tests/                  автоматические проверки
tools/recover_db.py     проверка и восстановление повреждённой базы
tools/import_journal.py перенос журнала СЗ из Excel в базу
sz.ini.example          пример настройки общей папки

data/memos.db           база данных SQLite (создаётся при первом запуске)
data/memos.lock         временная блокировка во время записи (удаляется сама)
Служебные записки/      документы Word: <год>/<номер СЗ>/<номер СЗ>.docx,
                        например 2026/НТЦ-0001-26/НТЦ-0001-26.docx
```

## Переход с браузерной версии (SZ.html)

Формат базы тот же. Положите программу в ту же общую папку, где лежал `SZ.html`, и запустите
`SZ.vbs`: она откроет существующую `data/memos.db` и продолжит нумерацию, старые записки и
документы Word останутся на месте. Документы формируются в точности как раньше.

Переведите на программу всех пользователей сразу: браузерная версия перезаписывает файл базы
целиком, и пока программа держит базу открытой, у браузера сохранение не пройдёт.

## Перенос журнала из Excel

Если записки раньше вели в журнале Excel, его можно перенести в базу. Программу лучше закрыть
у всех. В PowerShell (пути замените своими):

```
& "\\server\Общие\СЗ\environment\python\python.exe" "\\server\Общие\СЗ\tools\import_journal.py" "C:\журнал.xlsx" "\\server\Общие\СЗ"
```

Берётся первый лист, колонки ищутся по заголовкам: «Объект» (тематика), «Номер СЗ», «Краткое
содержание» (текст), «Дата», «Ответственный» (исполнитель), «Кому». Остальные колонки, в том
числе «Номер СЗ в ИСУ КБ» и «Номер СЗ 1С», не используются.

- Новые тематики добавляются в справочник. Исполнители и адресаты ищутся в справочниках
  (по полному ФИО, «Фамилия И.О.», отделу); кого нет, тот записывается как в журнале.
- Сначала скрипт показывает, что внесёт, ошибки (строки с непонятным номером или датой не
  вносятся) и спрашивает подтверждение. Перед записью делается копия базы
  `data\memos-до-импорта-<дата>.db`.
- Номера, которые уже есть в базе, пропускаются, поэтому скрипт можно запускать повторно,
  например после исправления ошибок в журнале.
- После переноса нумерация в программе продолжается с наибольшего номера года.
- Документы Word не создаются; при необходимости откройте «Редактировать» на странице
  записки и сохраните СЗ для формирования Word.

## Настройки (Справочники → Настройки)

- **Наименование организации** печатается в шапке каждой СЗ, каждая строка отдельно.
- **Город** печатается под заголовком.
- **Префикс номера**: по умолчанию `НТЦ`.
- **Папка для документов Word**: путь внутри общей папки.
- **Общая папка на этом компьютере**: где лежат база и документы.

## Номер СЗ

Формат `НТЦ-XXXX-YY`: `XXXX` — порядковый номер с ведущими нулями, `YY` — две последние
цифры года из даты записки. С каждым годом нумерация начинается с `0001`. Номер присваивается
при сохранении и хранится в записке, поэтому смена префикса не меняет уже выпущенные номера.

## Страницы

- **Новая СЗ**: тематика работ, один или несколько адресатов, дата, текст, приложение,
  исполнитель; подписант подставляется сам. Справа сразу видно, как записка будет выглядеть
  в Word. Текст можно оформить: полужирный, курсив, размер, выравнивание (см. «Оформление
  текста»). После сохранения в папке создаётся документ Word. Набранный текст не пропадает при
  переходе на другие страницы, пока записка не сохранена.
- **Реестр**: список с поиском (по мере ввода) и фильтрами по тематике и году. Двойной щелчок
  открывает записку.
- **Просмотр СЗ**: все данные записки и лист, кнопки «Открыть Word», «Показать в папке»,
  «Редактировать», «Удалить из реестра» (файл Word при этом остаётся).
- **Статистика**: число СЗ за год, по месяцам (графиком или таблицей), по тематикам, адресатам
  и исполнителям.
- **Справочники**: сотрудники (ФИО, должность, телефон, подписант), адресаты (отдел,
  должность и ФИО руководителя), тематики работ, настройки. Запись изменяется двойным
  щелчком или кнопкой «Изменить».

Данные из справочников копируются в записку в момент создания, поэтому правка или удаление
сотрудника или адресата не меняет уже созданные СЗ.

## Шаблон СЗ (Arial 14)

Шапка с наименованием организации (полужирным, переносы как в настройках) →
«СЛУЖЕБНАЯ ЗАПИСКА» → город → дата слева и номер справа → адресаты справа
(должность и под ней «Фамилия И.О.», в дательном падеже) → тематика работ → обращение
(«Уважаемый Имя Отчество!», для нескольких адресатов «Уважаемые Коллеги!») → текст →
приложение → должность подписанта слева и его Фамилия И.О. справа → исполнитель и телефон
шрифтом 10.

### Оформление текста

Над полем «Текст» есть панель оформления, результат сразу виден на листе справа и в Word:

| Кнопка | Что делает | Клавиши |
|---|---|---|
| **Ж** / *К* / <u>Ч</u> | полужирный, курсив, подчёркнутый | Ctrl+B / Ctrl+I / Ctrl+U |
| 10–16 | размер шрифта выделенного текста (обычный — 14) | |
| выравнивание | по левому краю, по центру, по правому краю, по ширине | Ctrl+L / Ctrl+E / Ctrl+R / Ctrl+J |
| отступ | отступ первой строки абзаца 1,25 см вкл/выкл | |
| ↵ | перенос строки внутри абзаца | Shift+Enter |
| ✕ | убрать оформление: шрифт 14, по ширине, с отступом | |

Enter начинает новый абзац. По умолчанию абзац выровнен по ширине и с отступом первой
строки, как в шаблоне. При вставке текста из Word, браузера или почты сохраняются только
полужирный, курсив и подчёркивание, а чужие шрифты, цвета и размеры отбрасываются, чтобы
записки оставались единообразными.

Оформление хранится в колонке `memos.body_rich` (JSON). Обычный текст записки по-прежнему
лежит в `memos.body`, по нему работает поиск. У записок без оформления `body_rich` пустая.

В справочниках ФИО хранится полностью, в документе печатается кратко. Для адресата
должность и «Фамилию И.О.» в дательном падеже («Начальнику отдела», «Петрову П.П.») вносят
в справочник вручную, полное ФИО нужно для обращения по имени и отчеству.

Подписант один на всех: его отмечают галочкой в справочнике «Сотрудники» (у остальных
галочка блокируется, пока её не снимут), и он подставляется во все новые записки
вместе со своей должностью.

## Одновременная работа нескольких пользователей

Программа работает с файлом базы напрямую. Перед каждой записью она создаёт файл
`data/memos.lock`, причём создание атомарное: на сетевой папке его может создать только один
компьютер, остальные ждут (обычно доли секунды). Поэтому изменения разных людей не затирают
друг друга, а номера СЗ не повторяются. Изменения коллег появляются на экране сами в течение
нескольких секунд и при возврате в окно программы.

Если программа аварийно закрылась во время записи, блокировка считается брошенной через
минуту и снимается автоматически. Схема рассчитана на отдел (единицы и десятки
пользователей).

## Резервное копирование

Достаточно копировать папку `data/` и папку с документами.
Базу `data/memos.db` можно открыть любой программой для SQLite, например DB Browser for SQLite.

## Если не работает

- **«Cmd.exe не поддерживает пути UNC»** при запуске `SZ.bat` или `SZ-console.bat` из сетевой
  папки: это предупреждение, программа всё равно запускается. Чтобы его не было, запускайте
  `SZ.vbs` (см. «Запуск из сетевой папки»).
- **Окно не появляется**: запустите `SZ-console.bat`, в консоли будет текст ошибки.
- **«database disk image is malformed» (база повреждена)**: закройте программу у всех и запустите
  проверку (в PowerShell; путь замените своим):
  ```
  & "\\server\Общие\СЗ\environment\python\python.exe" "\\server\Общие\СЗ\tools\recover_db.py" "\\server\Общие\СЗ\data\memos.db"
  ```
  Скрипт не меняет исходный файл: он работает с копией в папке `data\восстановление-<дата>`.
  Если база исправна, он так и скажет. Если повреждена, перенесёт всё, что читается, в
  `memos-восстановлена.db` и напишет, сколько строк не удалось прочитать. Её нужно положить в
  `data\` под именем `memos.db` вместо повреждённой (повреждённую не удаляйте, а переименуйте).
  Служебные файлы `memos.db-journal` и `memos.db-wal` рядом с базой не удаляйте: в них может
  быть незаконченная запись.
- **Не открывайте `memos.db` в текстовом редакторе** (VS Code, Блокнот): сохранение такого файла
  портит базу.
  Ошибки при обычном запуске пишутся в файл `sz-errors.log` во временной папке пользователя
  (`%TEMP%`).
- **«Не удалось открыть базу» / «Нет прав на запись»**: проверьте, что общая папка доступна и
  у пользователя есть право записи.
- **«База занята другим пользователем»** дольше минуты: в сообщении указано, кто держит
  блокировку. Если этот человек ничего не сохраняет, удалите `data/memos.lock`.
- **«Не удалось записать … файл открыт в Word»**: закройте документ в Word и повторите.

## Для разработчика

```
environment\python\python.exe -m unittest discover -s tests
```

Пересборка окружения на компьютере с интернетом (скачивает Python с NuGet и PyQt5 с PyPI,

```
python environment/build_environment.py
```
